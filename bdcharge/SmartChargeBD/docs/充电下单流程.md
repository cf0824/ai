# 充电下单流程

1. 前端点击开始充电按钮请求后端充电下单接口
2. 后端校验无误后准备开始发起充电
3. 后端变更用户余额并更新余额明细
4. 后端创建订单并置订单状态为初始状态0（订单创建）
5. 后端调用硬件充电api（异步）
6. 后端返回给前端订单号
7. 前端根据订单号轮训请求后端订单查询接口，后端返回订单状态
    - 0-订单创建
    - 1-充电中
    - 9-超时关闭
8. 前端判断返回状态是0时延时后继续轮训，否则根据状态跳转到充电或者超时页面
9. 充电下单流程结束


## 注意事项

- 某设备id存在订单未完成状态时（0、1）不允许再创建订单（充电下单时需校验）
- 要考虑并发与事务处理
- 订单查询接口可新增，也可复用现有的订单详情接口（前后端商量）
